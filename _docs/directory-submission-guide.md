## 2. The Component Gallery

**URL:** https://component.gallery/contribute/  
**What it is:** Curated design systems that must be usable for real product development with evidence of underlying code/documentation.

### Their criteria
- Distinct from existing featured systems
- Usable for real product development (evidence of underlying code—docs, tokens, or tools count)

Shizen qualifies: we have a public spec, token definitions, a working prompt builder, and copy-paste prompts plus CSS token examples.

**URL:** https://design-systems.fyi/  
**Note:** This site sometimes returns 503. If it’s back online, look for a “Submit”, “Suggest”, or “Contribute” link (often in footer or a “Add a system” page).

### Suggested one-liner for any form
**Shizen Design System (CSSKitsune)** — Japanese aesthetic tokens and AI-ready prompts; open spec, prompt builder, free Wabi-Sabi pack. https://csskitsune.com

### Suggested description (if they ask for more)
Shizen is a design system built on Japanese aesthetic principles (ma, wabi-sabi, kisetsukan). It provides semantic color and spacing tokens, typography and motion guidance, and copy-paste AI prompts for Cursor, Figma, Webflow, OBS, Godot, and Defold. The specification is open (CC BY 4.0). No single framework—token-based and prompt-first for any stack.
