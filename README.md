# CSSKitsune — Shizen Design System

The **Japanese Design System for AI-era developers**: aesthetic tokens, cultural vocabulary, and copy-paste prompts for authentic Japanese-style UI.

**Shizen** (自然) means nature, naturalness — the effortless quality at the heart of Japanese aesthetics. This repo is the source for [csskitsune.com](https://csskitsune.com).

---

## Try it

- **[Live site](https://csskitsune.com)** — Landing, email signup, and links
- **[Shizen Prompt Builder](https://csskitsune.com/prompt-builder.php)** — Pick platform, aesthetic, season, and mood → get a ready-to-paste AI prompt
- **[Spec (v1.0)](https://csskitsune.com/spec.php)** — Full specification: tokens, spacing (ma), typography, motion, naming
- **[Free Wabi-Sabi pack](https://csskitsune.com/prompt-pack-wabi-sabi.php)** — One palette, one prompt; print or save as PDF

---

## What’s in the repo

- **Landing** (`index.php`) — Hero, email capture (log file), teaser
- **Prompt Builder** (`prompt-builder.php`) — Interactive builder + live aesthetic preview
- **Aesthetic packs** (`data/aesthetic-packs.json`) — Five packs: Wabi-Sabi, Shinto, Edo Ink, Sakura, Yoru
- **Spec** (`spec.php`) — Shizen v1.0 specification (open, CC BY 4.0)
- **Wabi-Sabi pack page** (`prompt-pack-wabi-sabi.php`) — Print-friendly lead magnet
- **SEO** — `includes/seo-config.php`, `robots.txt`, `sitemap.xml`

Stack: PHP, no database (email signups go to `data/signups.log`).
